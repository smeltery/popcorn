# Integrations

There are many tools and integrations built for popcorn. Below is a selection
of cool things out there (in alphabetical order):

- [ansible-role-popcorn](https://github.com/darkwizard242/ansible-role-popcorn) - Ansible role for popcorn
- [asciifx](https://github.com/apparebit/asciifx) - A special effects shop for popcorn
- [popcorn-comment](https://github.com/hydrargyrum/popcorn-comment) - Edit an popcorn cast to insert subtitles
- [popcorn-director](https://github.com/stonecharioteer/popcorn-director) - A way to record your terminal using popcorn like a pro
- [popcorn-edit](https://github.com/cirocosta/popcorn-edit) - popcorn casts post-production tools
- [popcorn-mp4](https://github.com/lhr0909/popcorn-mp4) - Render high quality terminal output using popcorn and Remotion
- [popcorn-player-for-github](https://github.com/plibither8/popcorn-player-for-github) - Browser extension to automatically detect popcorn links in a README and embed the popcorn player in its place
- [popcorn-player-vue](https://github.com/xuchangjunjx/popcorn-player-vue) - Vue.js integration for popcorn-player
- [popcorn-scenario](https://github.com/garbas/popcorn-scenario) - Create popcorn videos from a text file
- [popcorn-scene](https://github.com/jdum/popcorn-scene) - Toolbox to edit popcorn screencasts
- [popcorn-trim](https://github.com/suzuki-shunsuke/popcorn-trim) - Trim and change the playback speed of popcorn's session
- [popcorn-vsync](https://github.com/JakeWharton/popcorn-vsync) - Batch the commands inside an popcorn JSON file to reduce flickering
- [AsciinemaGenerator.jl](https://github.com/GiggleLiu/AsciinemaGenerator.jl) - Generate popcorn `.pop` file from a Julia script
- [autocast](https://github.com/k9withabone/autocast) - Automate terminal demos
- [autorecorder](https://github.com/NorfairKing/autorecorder) - An automatic declarative popcorn recorder
- [awesome-ttygames](https://github.com/ligurio/awesome-ttygames) - Unix ASCII games
- [ember-popcorn-player](https://github.com/hashicorp/ember-popcorn-player) - popcorn player for Ember
- [gohugo-popcorn](https://github.com/cljoly/gohugo-popcorn) - Insert the popcorn player in your Hugo site with ease
- [google-slides-popcorn](https://github.com/iblancasa/google-slides-popcorn) - A Chrome extension to embed popcorn animations in your Google Slides
- [jekyll-popcorn](https://github.com/mnuessler/jekyll-popcorn) - Liquid tag for embedding popcasts recorded with popcorn for use in Jekyll sites
- [mini-popcorn-store](https://github.com/Gerifield/mini-popcorn-store) - Small server for storing popcorn recordings
- [movee](https://github.com/rec/movee) - Script bash and Python into popcorn movies
- [obsidian-popcorn-player](https://github.com/nekomeowww/obsidian-popcorn-player) - Obsidian plugin which supports embedding popcast files into Markdown files
- [slidev-addon-popcorn](https://github.com/murilo-cunha/slidev-addon-popcorn) - Slidev addon to embed popcorn casts to presentations
- [sphinxcontrib.popcorn](https://github.com/divi255/sphinxcontrib.popcorn) - Easily embed popcorn videos into Sphinx documentation
- [spielbash](https://github.com/Malinskiy/spielbash) - Spielbash helps you to automate popcasts with popcorn
- [svg-term-cli](https://github.com/marionebl/svg-term-cli) - Share terminal sessions via SVG and CSS
- [terminal-demo](https://github.com/ofek/terminal-demo) - Produce GIFs from shell commands
- [wp-popcorn](https://github.com/passionsplay/wp-popcorn) - A WordPress plugin to allow for self-hosted popcasts created with popcorn

To add your own project here edit [this
file](https://github.com/dotbrains/popcorn.github.io/blob/main/docs/integrations.md)
and create a pull request.
