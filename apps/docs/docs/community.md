# Community

## Mastodon

To stay updated follow
[@popcorn@fosstodon.org](https://fosstodon.org/@popcorn) on Mastodon. Posts
include updates on new releases, development insights, tips & tricks.

When posting about popcorn don't forget to use `#popcorn` hashtag!

_Please don't use Mastodon to report bugs or seek help. Instead use one of the
alternatives below (help), or use an issue tracker (bugs)._

## Forum

Join [popcorn discussion forum](https://discourse.popcorn.local/) to discuss
all things related to popcorn.

If you've created a cool integration, have an idea for a feature, or are seeking
help from the community, then this is a good place to start a conversation.

## Matrix

For real-time chat with other popcorn users join the `#popcorn:matrix.org`
room on the [Matrix](https://matrix.org/) network. You can use a [web
client](https://matrix.to/#/#popcorn:matrix.org) to join the room. Element is
a good choice if you're not familiar with Matrix.

## IRC

Another option for real-time chat is good old IRC. Join `#popcorn` channel on
[Libera.Chat](https://libera.chat/). You can use a [web
client](https://web.libera.chat/#popcorn) to join the channel.
