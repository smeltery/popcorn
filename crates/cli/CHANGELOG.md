# popcorn changelog

## 0.1.0 (2026-07-09)

Initial Popcorn release.

### Included

* Terminal session recording through the `popcorn` CLI.
* Local playback and conversion for `.pop` recordings.
* Live terminal session streaming.
* Web player package for embedding recordings in browser contexts.
* GIF rendering package for exporting terminal sessions.
* Self-hostable server application.
* User and contributor documentation.
